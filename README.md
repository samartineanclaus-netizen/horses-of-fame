# Horses of Fame — public website MVP

Next.js 16 App Router marketing site for Chapter I — Genesis.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

Option 1: drag the whole `hof-site` folder into Vercel Drop.
Option 2: push this folder to GitHub and import the repository into Vercel.

## Not connected yet

- Connect Wallet button is UI only.
- Mint button is UI only.
- OpenSea Drop URL is not wired.
- Racing dashboard / voting / leaderboards are not part of this public MVP yet.

## Content basis

Built around the locked HOF Chapter I model: 2,222 Genesis NFTs, 22 HOF racers, 2,200 voters, 4,800 total VP, 6 seasons, 60 races and $48K season rewards.
